📊 詳細分析 / Detailed Analysis

📐 計算公式 / Calculation Formulas

波長自動更新 / Wavelength Auto-Update:
• 1310nm: 基準線和待測光纖衰減係數 = 0.35 dB/km
• 1550nm: 基準線和待測光纖衰減係數 = 0.20 dB/km
• 自訂: 使用用戶設定的衰減係數範圍
實際總損耗 / Actual Total Loss:
總損耗 (dB) = 基準功率 - 測量功率
Total Loss (dB) = Baseline Power - Measured Power
基準總損耗 / Baseline Total Loss:
基準總損耗 = 基準線損耗 + 基準LC損耗
基準線損耗 = (基準線A + 基準線B) × 基準線衰減係數 ÷ 1000
基準LC損耗 = 基準LC對數 × 基準LC每對損耗
Baseline Total Loss = Reference Cable Loss + Baseline LC Loss
淨光纖損耗 / Net Fiber Loss:
淨光纖損耗 = 總損耗 - 基準總損耗 - 測試LC損耗
Net Fiber Loss = Total Loss - Baseline Total Loss - Test LC Loss
測試連接器損耗 / Test Connector Loss:
測試LC損耗 = 測試LC對數 × 測試LC每對損耗
Test LC Loss = Test LC Pairs × Test LC Loss per Pair
理論光纖損耗 / Theoretical Fiber Loss:
理論損耗 = 光纖長度 (km) × 衰減係數 (dB/km)
Theoretical Loss = Fiber Length (km) × Attenuation Coefficient (dB/km)
品質判斷標準 / Quality Assessment Criteria:
• 優良 Good: 淨光纖損耗 ≤ 理論損耗最大值 + 0.3 dB
• 可接受 Acceptable: 理論損耗最大值 + 0.3 dB < 淨光纖損耗 ≤ 理論損耗最大值 + 0.8 dB
• 不良 Poor: 淨光纖損耗 > 理論損耗最大值 + 0.8 dB
