📐 計算公式 / Calculation Formulas

光纖損耗 / Fiber Loss:
Loss (dB) = A (基準功率) - B (測量功率)
Loss (dB) = A (Baseline Power) - B (Measured Power)
理論衰減 / Theoretical Attenuation:
理論損耗 = 長度 (km) × 衰減係數 (dB/km)
Theoretical Loss = Length (km) × Attenuation Coefficient (dB/km)
波長衰減係數 / Wavelength Attenuation Coefficients:
• 1310 nm: 0.30 ~ 0.35 dB/km (每公尺 0.0003 ~ 0.00035 dB)
• 1550 nm: 0.17 ~ 0.20 dB/km (每公尺 0.00017 ~ 0.0002 dB)
品質判斷標準 / Quality Assessment Criteria:
• 優良 Good: 實際損耗 ≤ 理論最大值 + 0.5 dB
• 可接受 Acceptable: 理論最大值 + 0.5 dB < 實際損耗 ≤ 理論最大值 + 1.0 dB
• 不良 Poor: 實際損耗 > 理論最大值 + 1.0 dB
• 異常 Abnormal: 實際損耗 > 20 dB (連線可能中斷)
